## Overview
High-performance luxury skincare ecommerce experience. Features interactive 3D 360-degree bottle rotation, smooth scroll-driven product ingredient carousels, responsive typography, and self-hosted visual assets.

## Features
- **Interactive 3D 360° Bottle Rotation:** Smooth multi-frame interactive product examination on cursor movement.
- **Scroll-Driven Story & Ingredients Reveal:** Dynamic SVG clip-path transitions and accordion interactive tabs.
- **Fluid Smooth Scroll:** Ultra-smooth inertia scrolling powered by Lenis and GSAP.
- **100% Self-Hosted & Zero External Reliance:** All images, 360-degree product frames, SVG icons, fonts, and scripts are stored strictly in the local folder.

## Getting Started
```bash
npm start
# or
node serve.js
```
Open `http://localhost:3000` in your browser.
